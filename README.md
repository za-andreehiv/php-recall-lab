# PHP Recall Lab

Первая боевая версия личного тренажёра PHP + MySQL без OpenAI API.

## Возможности

- один защищённый аккаунт;
- ежедневная панель;
- карточки с интервалами 10 минут, 1, 3, 7, 14, 30, 45 и 60 дней;
- задания с безопасными детерминированными проверками;
- прогресс по темам 11.01–12.04;
- первые 100 задач отмечаются как пройденный фундамент;
- копирование контекста для проверки в десктопном приложении ChatGPT;
- cron для подготовки ежедневной сессии.

## Требования

- PHP 8.1 или новее;
- расширения PDO и pdo_mysql;
- MySQL 5.7+ или MariaDB 10.4+;
- HTTPS;
- cron с возможностью запускать PHP CLI.

## Установка в /it/courses/

1. Скачайте артефакт php-recall-lab из раздела Actions или архив репозитория.
2. Загрузите содержимое в public_html/it/courses/.
3. Скопируйте config.example.php в config.php.
4. Заполните подключение к созданной базе MySQL. config.php не отправляйте в Git.
5. Откройте https://vseposisteme.ru/it/courses/install.php.
6. Придумайте логин и длинный пароль.
7. После успешной установки удалите install.php с хостинга.
8. Войдите через login.php.

Если сервер возвращает ошибку 500, временно уберите строку Options -Indexes из .htaccess: некоторые хостинги запрещают эту директиву.

## Cron

Узнайте в панели хостинга абсолютный путь к PHP и к сайту. Пример ежедневного запуска в 00:05 по времени сервера:

    5 0 * * * /usr/bin/php /home/ACCOUNT/public_html/it/courses/cron/daily.php >> /home/ACCOUNT/logs/php-recall-cron.log 2>&1

Сначала выполните команду вручную. Скрипт работает только из CLI и использует блокировку MySQL, поэтому параллельный запуск не создаёт дубли.

## Проверка работ через десктопное приложение

На странице задания нажмите «Скопировать для проверки», вставьте пакет в текущий чат, затем сохраните полученный комментарий и статус в форме под заданием.

## Безопасность

- config.php исключён из Git;
- пароль хранится через password_hash;
- формы используют CSRF-токены;
- вход ограничивается паузой после ошибок;
- произвольный PHP и SQL на сервере не выполняются;
- готовые ответы не передаются в браузер до явного открытия;
- после установки install.php нужно удалить.

## Ограничения первой версии

Проверки PHP и SQL анализируют структуру ответа по правилам задания. Безопасный запуск произвольного кода потребует отдельной изолированной инфраструктуры и не включён в shared-hosting версию.
