# PHP Recall Lab — отдельный выпуск «Курс 447 + карточки»

Чистая версия платформы без прежних 100/140 заданий и без таблиц старого тренажёра.

## В составе

- 447 самостоятельных заданий PHP + MySQL;
- полная теория и точные исходные данные внутри каждого задания;
- автоматическая структурная проверка PHP и SQL;
- 444 карточки интервального повторения по 148 темам;
- шаги: 10 минут, 1, 3, 7, 14, 30, 45 и 60 дней;
- карточки ошибок;
- один личный аккаунт;
- ежедневная cron-сводка.

Произвольный PHP-код не выполняется. Проверяются синтаксис, обязательные элементы и безопасная структура.

## Установка

Этот выпуск устанавливается только на пустую базу. Полная инструкция находится в `RESET-AND-INSTALL-RU.md`.

1. Создайте пустую папку сайта.
2. Очистите таблицы базы PHP Recall Lab.
3. Создайте `config.php` по примеру.
4. Откройте `install.php`.
5. Создайте личный аккаунт.

Не загружайте этот архив поверх старой версии без предварительной очистки базы.
