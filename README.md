# PHP Recall Lab v2

Личный тренажёр PHP + MySQL без OpenAI API, подготовленный для размещения в vseposisteme.ru/it/courses/.

## Что входит

- личный аккаунт с защищённым входом;
- полный маршрут из 447 самостоятельных заданий;
- темы: основы PHP, массивы, условия, циклы, функции, формы, сессии, файлы, MySQL/PDO, HTTP и авторизация;
- старый блок 11.01–12.04 и первые 100 принятых задач сохранены;
- статическая проверка синтаксиса PHP через token_get_all с TOKEN_PARSE без запуска пользовательского кода;
- безопасная проверка структуры SQL без выполнения запроса;
- карточки собственных ошибок;
- интервалы 10 минут, 1, 3, 7, 14, 30, 45 и 60 дней;
- открытие заданий блоками по 10: следующий блок после 8 принятых;
- перенос проверки в десктопное приложение ChatGPT, если автоматических правил недостаточно;
- cron для ежедневной сессии.

Все теоретические материалы, задания, проверки и тренажёры находятся внутри платформы. Внешние учебные ссылки в интерфейсе отсутствуют.

## Требования

- PHP 8.1 или новее;
- PDO, pdo_mysql и mbstring;
- MySQL 5.7+ или MariaDB 10.4+;
- HTTPS;
- cron и PHP CLI.

## Новая установка

1. Скачайте ZIP из GitHub Actions или архив ветки main.
2. Загрузите содержимое в public_html/it/courses/.
3. Скопируйте config.example.php в config.php.
4. Укажите параметры MySQL и проверьте base_path: /it/courses.
5. Откройте https://vseposisteme.ru/it/courses/install.php.
6. Создайте личный логин и пароль длиной не менее 12 символов.
7. После установки удалите install.php.

## Обновление с первой версии

1. Сделайте резервную копию файлов и базы.
2. Загрузите новые файлы поверх старых, не заменяя config.php.
3. Войдите в тренажёр.
4. Откройте https://vseposisteme.ru/it/courses/upgrade.php.
5. Нажмите «Установить обновление курса».
6. После успеха удалите upgrade.php.

Старые результаты, карточки и пользователь сохраняются.

## Как сдаётся задание

1. Пользователь пишет решение в редакторе сайта.
2. PHP разбирается встроенным парсером, но не выполняется.
3. SQL проверяется по структуре и списку опасных команд, но не запускается на боевой базе.
4. При ошибке создаётся карточка с конкретной причиной.
5. После исправления автопроверка отмечает задание принятым.
6. Если задача требует смысловой проверки, кнопка «Скопировать пакет для чата» формирует условие и ответ. Итог из чата сохраняется в карточке задания.

## Ограничение проверки

Без отдельного изолированного контейнера сайт не запускает произвольный PHP-код и не выполняет ученический SQL. Это защищает shared hosting. Автопроверка выявляет синтаксические ошибки, отсутствующие обязательные конструкции и опасные команды; проверку поведения сложных программ нужно выполнять локально или через чат.

## Cron

Пример ежедневного запуска в 00:05:

    5 0 * * * /usr/bin/php /home/ACCOUNT/public_html/it/courses/cron/daily.php >> /home/ACCOUNT/logs/php-recall-cron.log 2>&1


## Формат заданий версии 2.2

Все 447 заданий работают без внешнего учебника. На странице каждого задания есть цель, вся необходимая теория, точные исходные данные, пошаговое условие, стартовый код, ожидаемый результат, ограничения, самопроверка, критерии автопроверки и две постепенные подсказки. Неизменённый стартовый шаблон не принимается.

После обновления файлов один раз откройте `/it/courses/upgrade.php` и нажмите кнопку установки обновления. Прогресс, попытки и интервальные повторения сохраняются.
