# Чистая установка «Курс 447 + карточки»

Этот выпуск предназначен только для новой пустой базы данных. Он не обновляет старую установку.

## 1. Сохраните резервную копию

Перед удалением скачайте:

- архив старой папки `/public_html/it/courses/`;
- экспорт текущей базы данных в phpMyAdmin;
- текущий `config.php`.

Не удаляйте резервные копии, пока новая версия не откроется и вход не будет проверен.

## 2. Очистите папку сайта

В файловом менеджере хостинга переименуйте старую папку:

`courses` → `courses-backup`

Создайте новую пустую папку `courses` и загрузите в неё содержимое каталога `php-recall-lab-course-447` из архива выпуска.

Такой способ безопаснее немедленного удаления. После успешной проверки старую папку можно удалить.

## 3. Очистите базу данных

В phpMyAdmin:

1. Откройте базу, используемую старым сайтом.
2. Откройте вкладку «Структура».
3. Выберите все таблицы.
4. Выберите действие «Удалить таблицу / DROP».
5. Подтвердите удаление.

Удаляйте таблицы только в базе PHP Recall Lab. Не удаляйте саму базу и не выбирайте базы других сайтов.

## 4. Настройте подключение

Скопируйте `config.example.php` в `config.php` и укажите:

- имя пустой базы;
- пользователя MySQL;
- пароль;
- `base_path` = `/it/courses`;
- часовой пояс `Europe/Moscow`.

## 5. Выполните установку

Откройте:

`https://vseposisteme.ru/it/courses/install.php`

Создайте личный логин и пароль длиной не менее 12 символов. Установщик создаст:

- 447 заданий;
- 18 разделов;
- 444 карточки: по три на каждую из 148 тем;
- интервалы 10 минут, 1, 3, 7, 14, 30, 45 и 60 дней.

Сначала будут активированы три карточки первой темы. Остальные карточки будут добавляться после принятия первого задания соответствующей темы.

## 6. Настройте cron

Команда для ежедневного запуска:

`/usr/bin/php /home/ИМЯ_АККАУНТА/public_html/it/courses/cron/daily.php`

Точный путь к PHP и домашнему каталогу возьмите в панели хостинга. Запускайте один раз в день, например в 04:10.

Cron обновляет дневную сводку. Сроки карточек работают и без cron, поскольку рассчитываются при ответе.
